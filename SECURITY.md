# Security

Do not post credentials, real-device storage or exploit details in public issues.
Use [GitHub private vulnerability reporting](https://github.com/rafaelborges29/pebble-metro/security/advisories/new)
(**Security → Report a vulnerability**) for confidential reports. If GitHub says
reporting is unavailable, do not post sensitive details publicly; there is no
separately published email fallback or response-time commitment.

Include the affected version/commit, impact and minimal reproduction with
artificial data. Review fixes against current main; older releases do not have a
separate security-backport policy. Never run a live upload, hardware installation
or destructive reset as part of a report.

For ordinary bugs/features, see [Contributing](CONTRIBUTING.md#reporting-issues).
